# Milestone 3 Accessibility and Visual Design

## Accessibility Fixes

- Added descriptive alt text to images so screen readers can understand the images.
- Added page titles to all three HTML pages.
- Used semantic HTML elements such as header, nav, main, section, and footer.
- Added labels to all contact form fields.
- Added fieldset and legend to organize the contact form.
- Added accessible error messages for required form fields.
- Added aria-invalid to form fields when they contain errors.
- Checked text and background colors for WCAG AA contrast.

## Gestalt Principles

### Proximity
I used proximity to group my project cards together so visitors can easily see that the projects are related.

### Similarity
I used similarity by giving buttons and navigation elements consistent styling throughout my website.

## Color Palette

I used the same color palette across all three pages to create a consistent visual design.

Primary color: #1d3557

Secondary color: #457b9d

Background color: #f1faee

Text color: #222222
